# RQ5 analysis data

This bundle contains analysis inputs and frozen reconstructed maps.
There are no videos or images. See ../README.md for reproduction commands and
../PROVENANCE.md for the difference between reconstruction and historical reuse.

## Move Near data

move_near_504/<model>/ contains episodes.csv, trajectories.csv, run_config.json
and allMetrics/<scene_id>/. There are 504 scenes for each of eo1, gr00t, pi0 and
spatialvla-4b. Scene IDs range from 0 to 503. In episodes.csv, failure=0 is pass
and failure=1 is fail; the final success field in log.json is authoritative.

Each episode directory includes log.json plus the 13 metric filenames defined
by experiments/RQ2_baselines/catalogue.py. Empty JSON arrays for unavailable
metrics are retained: missingness must not be replaced by a numeric score.
Trajectory CSVs retain all TCP steps needed by the SBFL voxelizer.

Raw action streams, per-step TCP JSON duplicates, execution timing metrics,
DeepHyperion feature CSVs and media are not needed by these analyses and are
not part of this bundle. Original experiment files remain on the server.

## Maps and references

reconstructed_pickup_maps/folds/<configuration>/<held-out run>/model/ contains
320 reconstructed maps, with the 34 SBFL scores and original provenance.
These are the files actually used for RQ5, not the historical original RQ1 maps.

reference/selection stores the final fixed-pass selection (seed 20261028).
reference/sbfl and reference/baselines store metrics and original configurations.
reference/tables stores the previously exported paper tables. predictions.csv.gz
is regenerated by a full run and is not needed as an input to reproduce tables.

scenes_504 stores the exact scene specifications, prompt list, cell/pose
metadata and generation report matching the run configuration fingerprints.

files_manifest.csv lists the relative path, byte count and SHA-256 of every
other file in this directory. rq5_reproduce.py verify checks the full manifest
and the episode outcomes, scene hashes and sample constraints.

The local .gitattributes disables newline conversion for these artifacts, so
SHA-256 fingerprints remain stable when the repository is cloned on Windows.
